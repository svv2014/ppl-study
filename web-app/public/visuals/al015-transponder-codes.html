AL-015 — Transponder Codes, Squawks, Mode C Requirements

Transport Canada · CARs 601.03, 605.35 · AIM RAC 1.9 · TP 12880E Ch.7 · PPL Written Exam

Transponder Modes
Mode A
4-Digit Identity Code (Squawk)
Transmits the 4-digit octal code set by the pilot (e.g. 1200, 7700). Allows ATC radar to identify the return. No altitude information.
Squawk code range: 0000–7777 (octal)
Mode C
Pressure Altitude Encoding
Transmits pressure altitude from the encoding altimeter. Gives ATC an independent altitude readout alongside the radar return. Required in designated airspace.
Pressure altitude — not indicated altitude
Mode S
Selective Address / ADS-B
Each aircraft has a unique 24-bit address. Supports advanced ATC surveillance and is the basis for ADS-B. Provides identity, altitude, and enhanced data.
Required in some controlled airspace
Special Squawk Codes — Memorize These
1200
VFR Default (Canada)
Standard VFR code when ATC has not assigned a specific code
7700
Emergency
Any emergency — distress or urgency. Set immediately when declaring MAYDAY or PAN-PAN
7600
Radio Failure (NORDO)
Lost communications. ATC will attempt light signals; continue to destination per AIM
7500
Hijack / Unlawful Seizure
Set only under unlawful interference. ATC alerts authorities immediately
1000
IFR (assigned)
ATC-assigned code for IFR flights. Only set when instructed
