The Coordinate Grid
Key Facts — Latitude & Longitude

1° of Latitude

60 NM
everywhere on Earth

Because 1 minute of arc = 1 nautical mile by definition. So 60 minutes = 60 NM = 1 full degree.

VNC Grid Spacing

30′
per grid line on the VNC chart

Both latitude and longitude grid lines on a VFR Navigation Chart are printed every 30 minutes of arc — each grid square is 30′ × 30′.

Position Format

N DD°MM′
W DDD°MM′
ATC reporting format

Latitude uses 2-digit degrees; longitude uses 3-digit degrees (up to 180°). Always include N/S and E/W.

Meridian Convergence — Longitude Distance Varies

Why Longitude Distance Shrinks with Latitude

Meridians converge toward the poles. At the equator they are equally spaced. As you fly north into Canada, the same angular separation (1°) covers less ground distance.

1° lon ≈ 60 NM × cos(latitude)

At equator (0°): cos(0°) = 1.0 → 60 NM
At 45°N: cos(45°) ≈ 0.71 → ≈ 42 NM
At 50°N: cos(50°) ≈ 0.64 → ≈ 38.6 NM
At 60°N: cos(60°) = 0.50 → ≈ 30 NM

Exam tip: you won't need to calculate this — but you must know that longitude distance is less than 60 NM per degree in Canada, and decreases as you go north.

How to Read a Position from the VNC Grid

Step-by-Step Method

1. Find the nearest printed degree label on the chart border (e.g., 45°N or 076°W).

2. Count grid lines from that label toward your point. Each grid line = 30′.

3. Estimate remaining minutes visually between the grid lines.

4. Combine: degree label + grid steps + estimate = your coordinate.

Worked Example

An airport sits one grid line north of the 45°N parallel, and halfway between that grid line and the next.

45° + 30′ (one grid line) + 15′ (halfway) = 45°45′N

Apply the same method for longitude using the W labels on the top/bottom border.

Memory Hook — Key Exam Facts

1° LAT 1 degree of latitude = 60 NM, always. One minute of arc = one nautical mile by definition. This is exact and constant everywhere on Earth.
VNC GRID Grid lines every 30 minutes — count two grid lines to cover one full degree (60 NM). Each grid square holds one MEF value.
LONGITUDE Longitude distance shrinks as you go north — meridians converge. At 60°N, 1° of longitude is only ≈ 30 NM. Use latitude for distance math, not longitude.
PARALLELS Parallels (lat lines) run east–west, evenly spaced. Meridians (lon lines) run north–south, converging at the poles.
POSITION FORMAT Report as N DD°MM′, W DDD°MM′ — latitude first, longitude second, hemisphere always specified. All Canadian positions are N and W.
