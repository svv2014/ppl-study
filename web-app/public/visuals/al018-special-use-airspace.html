AL-018 — Special Use Airspace: Class F(R), MOAs, ADIZs

Transport Canada · CARs 601.04, 601.07, 602.145, 602.148 · AIM RAC 2.8, 9.0 · TP 12880E Ch.7 · PPL Written Exam

Types of Special Use Airspace
Class F(R)
Restricted Airspace
Airspace in which flight is prohibited unless authorization is obtained from the user agency — the authority listed in the Canada Flight Supplement (CFS) for that area (CAR 601.04). The user agency may be DND, TC, or another federal body.
Entry requires authorization from user agency
Class F(A)
Advisory Airspace
Airspace that warns pilots of a hazard (training, parachuting, glider ops, etc.) but does not prohibit entry (CAR 601.07). VFR pilots may enter; contacting the controlling agency before entry is recommended.
Entry permitted — contact agency recommended
MOA
Military Operations Area
Designated advisory airspace for military flight training. MOAs are not restricted — civil VFR flight is permitted, but pilots must check NOTAMs and contact the controlling agency before entering an active MOA.
Advisory — check NOTAM, contact controlling agency
ADIZ
Air Defence Identification Zone
Airspace boundary around Canada requiring identification of all inbound aircraft. VFR aircraft must file a DVFR (Defence VFR) flight plan before entering and submit a position report at the ADIZ boundary (CAR 602.145). Failure to comply can trigger a military intercept.
DVFR flight plan + position report required

ADIZ Entry Procedure — VFR Aircraft

1File a DVFR (Defence VFR) flight plan before departure. Include entry point, estimated time of entry, and transponder code.
2Squawk assigned code — ATC assigns a discrete code for ADIZ tracking. Squawk it from departure.
3Maintain schedule — cross the ADIZ boundary within ±5 minutes of the filed ETA. Deviations beyond this may trigger an interception.
4Position report at the ADIZ boundary — required per CAR 602.145; report aircraft identification, position, and altitude on the assigned ATC frequency when crossing.
5Close flight plan on landing as required. Failure to close may trigger a search and rescue response.

Memory Hook

R = RestrictedF(R) = Restricted = you need permission to enter. F(A) = Advisory = you can enter but be careful.
ADIZ = DVFRCrossing into Canadian ADIZ requires a DVFR flight plan filed before departure. No plan = possible intercept by CF-18.
NOTAM ALWAYSFor any special use airspace — F(R), F(A), MOA, TFR — always check NOTAMs. Activation and deactivation are notified via NOTAM.
