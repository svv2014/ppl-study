AL-018 — Special Use Airspace: Class F(R), MOAs, ADIZs

Transport Canada · CARs 601.14–601.17 · AIM RAC 2.8, 9.0 · TP 12880E Ch.7 · PPL Written Exam

Types of Special Use Airspace
Class F(R)
Restricted Airspace
Airspace in which flight is prohibited unless specific authorization is obtained from the controlling authority (usually DND, TC, or NAV CANADA). Listed in the Canada Flight Supplement (CFS).
Entry requires authorization
Class F(A)
Advisory Airspace
Airspace that warns pilots of a hazard (training, parachuting, glider ops, etc.) but does not prohibit entry. VFR pilots may enter but should exercise caution and may receive ATC advisories.
Entry permitted — caution advised
MOA
Military Operations Area
Designated block of airspace for military flight training. When active, civil VFR flight is not prohibited but is strongly discouraged. Check NOTAMs and contact the controlling unit before entering an active MOA.
Check NOTAM — avoid when active
ADIZ
Air Defence Identification Zone
Airspace boundary around Canada requiring identification of all inbound aircraft. VFR aircraft must file a DVFR (Defence VFR) flight plan before entering. Failure to do so can trigger a military intercept.
DVFR flight plan required before entry

ADIZ Entry Procedure — VFR Aircraft

1File a DVFR (Defence VFR) flight plan before departure. Include entry point, estimated time of entry, and transponder code.
2Squawk assigned code — ATC assigns a discrete code for ADIZ tracking. Squawk it from departure.
3Maintain schedule — cross the ADIZ boundary within ±5 minutes of the filed ETA. Deviations beyond this may trigger an interception.
4Report to ATC — position report at the ADIZ boundary if instructed, and maintain continuous monitoring of the assigned frequency.
5Close flight plan on landing as required. Failure to close may trigger a search and rescue response.

Memory Hook

R = RestrictedF(R) = Restricted = you need permission to enter. F(A) = Advisory = you can enter but be careful.
ADIZ = DVFRCrossing into Canadian ADIZ requires a DVFR flight plan filed before departure. No plan = possible intercept by CF-18.
NOTAM ALWAYSFor any special use airspace — F(R), F(A), MOA, TFR — always check NOTAMs. Activation and deactivation are notified via NOTAM.
