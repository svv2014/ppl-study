TAF Field Decode
Field Sample Format Meaning
Report Type TAF TAF or TAF AMD TAF = Terminal Aerodrome Forecast. AMD = amended (corrected) TAF issued between routine issuances.
Station ID CYYZ ICAO 4-letter ID Same station identifier as METAR. TAF issued for specific airports (not all airports have TAF).
Issue Time 151720Z DDHHMMz When the TAF was prepared: day 15, 1720 UTC. Not the valid period start.
Valid Period 1518/1618 DDHH/DDHH Forecast valid from day 15, 18 UTC to day 16, 18 UTC. Standard TAF = 24 hr; some airports 30 hr.
Wind 27015KT Same as METAR Prevailing wind forecast. Same format as METAR wind field.
Visibility P6SM SM or metres P6SM = prevailing more than 6 statute miles. TAFs typically use SM in Canada.
Weather / Cloud FEW030 OVC015 Same as METAR Same codes as METAR. CB appended after cloud amount for cumulonimbus (e.g. BKN020CB).
Change Groups TEMPO FM BECMG PROB Keyword + period + conditions Describe changes from the base forecast. See table below for details.
Change Indicator Keywords
FM
From (permanent change)
New conditions replace ALL previous forecast from the stated time. FM160800 = from day 16 at 0800 UTC onwards.
Always followed by DDHHmm (no period). Entire forecast resets. Most definitive change type.
TEMPO
Temporary fluctuations
Conditions expected for less than half of the period, each occurrence lasting less than 60 minutes.
TEMPO does not replace base — base conditions return between episodes. Period shown as DDHH/DDHH.
BECMG
Becoming (gradual change)
Conditions expected to change gradually during the period, reaching the new conditions by the end of the period.
Change is permanent once complete. Period shown as DDHH/DDHH. Slower transition than FM.
PROB30
30% probability
Conditions have a 30% chance of occurring during the stated period.
PROB40 = 40% chance. Typically used for thunderstorms. PROB30 alone (no TEMPO) = brief occurrence.
METAR vs. TAF — Key Comparison
METAR — Observed
Type
Actual current conditions (observation)
Frequency
Hourly (or SPECI for significant changes)
Valid period
Snapshot at time of observation
Use for
Departure planning; current conditions at destination
Change groups
None (it's an observation, not a forecast)
TAF — Forecast
Type
Weather forecast for a specific aerodrome
Frequency
4x/day (0000, 0600, 1200, 1800 UTC)
Valid period
24 hours (some airports 30 hours)
Use for
En route planning; ETA weather; alternate requirements
Change groups
FM, TEMPO, BECMG, PROB30/40

Memory Hook — TAF Decoding

VALID PERIODFormat is DDHH/DDHH. First group = start, second = end. Day can roll over (e.g. 1518/1618 spans two calendar days).
FM vs TEMPOFM = permanent reset of all conditions. TEMPO = temporary spike less than half the period; base forecast resumes between occurrences.
PROB3030% probability = plan for it if it would be a go/no-go condition. PROB30 thunderstorms = check alternate carefully.
METAR vs TAFMETAR = what IS. TAF = what WILL BE. Always check the latest METAR closest to your departure time; TAF for en route and destination.
