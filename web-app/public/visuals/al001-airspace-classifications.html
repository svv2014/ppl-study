Memory Hook — Classes at a Glance

A + BIFR only — clearance required. You won't fly here as a PPL student.
CClearance + radio — ATC separates IFR from VFR, not VFR from VFR.
DRadio contact only — no clearance, but must establish 2-way. ATC separates IFR only.
ENo requirements for VFR — but it's still controlled (ATC serves IFR).
FSpecial use — F(R) restricted, F(A) advisory. Always check NOTAM.
GUncontrolled — no ATC. Lower weather minimums. See and avoid.
