ROC-005 — VFR / IFR Communications Overview

AIM COM 4.0 · CARs Part VI · ISED RIC-21 · ROC-A Written Exam

VFR vs IFR — Key Differences

VFR Communications

  • Radio required in Class B, C, D and at MF aerodromes
  • Class E and G: no radio required (but recommended)
  • Self-announce at non-towered (MF) aerodromes on 122.8 MHz
  • Class D: radio contact required — no ATC clearance needed for VFR
  • VFR flight plans reported to FSS; not mandatory but strongly advised
  • Obtain ATIS before calling tower at controlled airports
  • Transponder Mode C required in Class B and C

IFR Communications

  • Radio mandatory at all times while operating IFR
  • ATC clearance required before entering controlled airspace
  • Position reports at all compulsory reporting points
  • Read back all ATC clearances — every mandatory item
  • Transponder Mode C required in all controlled airspace
  • Lost comms: squawk 7600, attempt 121.5 MHz
  • Cancel IFR on the ground or in the air when VMC
