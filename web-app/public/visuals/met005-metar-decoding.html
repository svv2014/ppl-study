Field-by-Field Decode
Field Sample Code Format Meaning
Report Type METAR METAR or SPECI METAR = routine hourly. SPECI = special report issued when significant change occurs.
Station ID CYYZ ICAO 4-letter ID Canadian stations start with CY. CYYZ = Toronto Pearson. Used to match TAF.
Date/Time (UTC) 151800Z DDHHMMz Day 15 of month, 1800 UTC (Z = Zulu/UTC). Always UTC — not local time.
Wind 27015KT DDDSSKT or DDDSSGGKT From 270° (west) at 15 knots. Gusts shown as 27015G25KT. VRB = variable direction. 00000KT = calm.
Visibility 15SM NNSMx or MNNNN (metres) 15 statute miles. P6SM = more than 6 SM (prevailing). Canadian METARs may use metres (e.g. 9000).
Present Weather -RA +SN TSRA Intensity + Descriptor + Phenomenon - = light, + = heavy, no sign = moderate. RA=rain, SN=snow, FG=fog, TS=thunderstorm, BR=mist, DZ=drizzle.
Cloud Amount FEW030 BKN080 AMTHHHx (hundreds of ft) 030 = 3,000 ft AGL. See cloud amount codes below. CB or TCU appended for cumulonimbus/towering Cu.
Temperature / Dew Point 18/08 TT/TDx in Celsius OAT 18°C, dew point 8°C. Spread = 10°C (no fog concern). Minus temps: M02 = -2°C.
Altimeter Setting A2992 ANNNN (inHg x100) 29.92 inHg. Canadian METARs also use Q format: Q1013 = 1013 hPa (QNH). Set on altimeter before flight.
Remarks RMK SLP214 Free text / coded SLP = sea-level pressure (1021.4 hPa if SLP214). May include PRESRR (pressure rising rapidly), peak wind, etc.

Memory Hook — METAR Reading Order

ORDERType → Station → Time → Wind → Vis → Wx → Cloud → Temp/DP → Altimeter → Remarks. Always read in sequence — don't skip fields.
CEILINGOnly BKN or OVC count as ceiling. FEW and SCT are not ceilings even if low. VFR ceiling limits apply to the lowest BKN/OVC layer.
UTCAll METAR times are UTC (Zulu). In Canada: UTC-3.5 to UTC-8 depending on province and DST. Know your offset for local interpretation.
ALTIMETERA2992 = 29.92 inHg = 1013 hPa. Set on altimeter to read correct MSL altitude. Update when given new ATIS or crossing altimeter zones.
