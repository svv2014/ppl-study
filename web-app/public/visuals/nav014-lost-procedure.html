Emergency Calls — Mayday vs Pan-Pan

MAYDAY — Distress Call

  • Used when aircraft, crew, or passengers are in grave and imminent danger
  • Repeated 3 times: "MAYDAY MAYDAY MAYDAY"
  • Followed by: callsign, nature of emergency, position, altitude, intentions, POB, any other relevant info
  • Frequency: current ATC freq or 121.5 MHz
  • Squawk: 7700
  • Examples: engine failure, fire, incapacitation

PAN-PAN — Urgency Call

  • Used when aircraft has a serious but non-immediately life-threatening condition
  • Repeated 3 times: "PAN-PAN PAN-PAN PAN-PAN"
  • Followed by: same information as Mayday
  • Frequency: current ATC freq or 121.5 MHz
  • Examples: lost, low fuel, medical problem, technical issue
  • Can be upgraded to Mayday if situation deteriorates
Transponder Squawk Codes
Squawk CodeMeaningWhen to Use
7700 Emergency Any emergency (engine failure, fire, Mayday call). ATC sees this immediately on radar.
7600 Radio Failure (NORDO) Complete loss of communications — both transmit and receive. ATC will try blind transmissions.
7500 Unlawful Interference / Hijack Aircraft is being hijacked. Do not squawk by accident — controllers will immediately scramble intercept.
1200 VFR — uncontrolled airspace Standard VFR squawk in Canada when not assigned a specific code by ATC
Assigned code ATC-assigned discrete code Always use ATC-assigned code when in Class C, D, or receiving radar service

Memory Hook
Memory Hook
  • 4 Cs — Climb, Confess, Communicate, Comply: The standard lost procedure. In that order — climb first to give yourself more options, confess quickly, communicate with ATC, then comply with instructions.
  • Squawk codes — "7700 is heaven, 7600 is mute, 7500 is hijacked": 7700 = emergency (worst), 7600 = radio out (silent), 7500 = hijack (severe).
  • Mayday = grave danger, Pan-Pan = urgent but not immediately fatal. When in doubt, say Mayday — downgrading is easy, upgrading too late is not.
  • 121.5 MHz is always monitored: ATC, SAR, and other aircraft monitor the guard frequency. If on any other freq and no contact, try 121.5.
  • Aviate · Navigate · Communicate — in that order. Never let radio work cause you to fly into terrain or lose control.
