Pre-Flight Checks & VFR Cruising Altitudes

Pre-Flight Planning Checklist

1. Charts: Current VNC/VTA, check NOTAMs
2. Weather: TAF, METAR, GFA, SIGMET/AIRMET
3. NOTAM/ATIS: Check departure, en-route, destination
4. Nav log: Complete all legs (TT → CH → GS → ETE)
5. Fuel: Trip + 30 min VFR reserve (day) / 45 min (night) + taxi (CAR 602.88)
6. Weight & Balance: Verify within limits
7. Performance: T/O, climb, cruise, landing distances
8. Flight plan: File VFR flight plan if required

VFR Cruising Altitudes

0–179° → Odd + 500
180–359° → Even + 500

Applies when flying above 3,000 ft AGL (CAR 602.34).

Examples:
Track 045° → 3,500 / 5,500 / 7,500 ft
Track 270° → 4,500 / 6,500 / 8,500 ft

Memory: "East is odd, West is even." The +500 ft separation keeps VFR and IFR traffic separated (IFR uses exact thousands).

Memory Hooks

Key Concepts to Remember

NAV LOG Nav log order: TT → TAS + Wind → WCA + GS → TH → VAR → MH → DEV → CH. Always work from True to Compass ("True Virgins Make Dull Companions" — TV: True, V: Variation, M: Magnetic, D: Deviation, C: Compass).
ALTITUDE VFR cruising altitude rule above 3,000 ft AGL: magnetic track 0–179° → odd thousands + 500 ft; 180–359° → even thousands + 500 ft (CAR 602.34).
MNEMONICS "TVMDCH" — True, Variation, Magnetic, Deviation, Compass, Heading. Apply East variation as subtract (CAUTION: Canadian charts use West variation as dominant — always check the isogonic line direction).
FILING File a VFR flight plan when flying more than 25 NM from the departure aerodrome or when requested by ATC. Activate on departure and close on arrival — failure to close triggers search and rescue.
