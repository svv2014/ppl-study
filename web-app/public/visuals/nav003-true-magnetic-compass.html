NAV-003 — True vs Magnetic vs Compass Heading

Transport Canada · TP 12880E Ch.9 · AIM GEN 1.1 · PPL Written Exam

The Three North References and TVMDC Chain
Definitions

Variation (VAR)

Angle between geographic and magnetic north. Shown on VNC charts as isogonic lines. Changes by location across Canada.

MH = TH + VAR(W)
MH = TH − VAR(E)

Deviation (DEV)

Angle between magnetic north and the cockpit compass reading. Caused by the aircraft's metal and electrical fields.

CH = MH + DEV(W)
CH = MH − DEV(E)

Track vs Heading

True Track = intended path over ground (from chart). True Heading = direction the nose points. Different when wind is present.

Convert TT → MH the same way as TH → MH using TVMDC.

Memory Hook — TVMDC

TVMDC True · Variation · Magnetic · Deviation · Compass — "Timid Virgins Make Dull Companions." Work left to right to convert, right to left to reverse.
EAST = LEAST East variation/deviation means subtract (MH/CH is less than TH/MH). West means add.
EXAM TIP Read the isogonic line on the VNC for the question's location. Eastern Canada = West variation (+). Western Canada = East variation (−).
