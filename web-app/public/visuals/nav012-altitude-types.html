NAV-012 — Altitude Types

Transport Canada · TP 12880E Ch.9 · PPL Written Exam
Vertical Stack — Altitude Reference Layers
All Six Altitude Types — Reference Table
Altitude Type Definition Altimeter Setting When It Matters
Indicated What the altimeter reads — uncorrected for temperature or non-standard pressure Current QNH (local altimeter setting) ATC clearances, cruising altitudes, IFR separation
True Actual height above mean sea level, corrected for temperature deviation from ISA QNH + temperature correction Terrain clearance calculations, precise navigation
Absolute Height above the terrain directly below the aircraft (AGL) Radio altimeter (no subscale setting) Low-level ops, landing flare, helicopter ops
Pressure Altitude above the standard datum plane (29.92 inHg / 1013.25 hPa) Set altimeter to 29.92 inHg Flight levels (above 18,000 ft), performance charts, transition altitude
Density Pressure altitude corrected for non-standard temperature — the altitude the atmosphere "feels" like Performance charts (not altimeter) Takeoff/landing distance, climb performance, engine power output
MSL / ASL Height measured from mean sea level — used for published elevations Referenced from sea level datum Airport elevation, obstacle clearance charts, terrain maps
Memory Hook
Memory Hook
  • "Indicated for ATC, Pressure for Performance, Density for Departures" — the three Ps of altitude
  • Cold = lower than indicated: On a cold day, true altitude is LOWER than indicated — you are closer to terrain than the altimeter suggests. "From high to low, look out below."
  • QNH vs QNE: QNH = local pressure (use for normal flight below FL180); QNE = 29.92 standard (use for flight levels and performance charts)
  • Density altitude = aircraft performance: High DA = longer takeoff roll, slower climb, reduced engine power — even if indicated altitude looks fine.
