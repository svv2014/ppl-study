Dead Reckoning — Five Steps
1
Measure True Track
Use plotter on VNC. Draw the route line; read the bearing where it crosses a meridian (true north reference).
2
Apply Wind (WCA + GS)
Solve the wind triangle on E6B. Get Wind Correction Angle and Ground Speed based on forecast winds aloft.
3
TVMDC Conversion
Convert True Heading → Magnetic Heading (apply Variation) → Compass Heading (apply Deviation).
4
Calculate Time
Distance ÷ Ground Speed × 60 = time in minutes. Mark checkpoints at regular intervals (every 10–15 min).
5
Verify In-Flight
At each checkpoint compare actual position to planned. Revise heading and ETA if drifting off track.
6
Log ETAs & ATAs
Record estimated and actual times. ATC and search-and-rescue use PLOG times if you go overdue.

Good Checkpoints

  • Distinctive, unlikely to be confused with surroundings
  • Perpendicular to track (easy to cross-confirm)
  • Spaced 10–20 NM apart (≈ every 10–15 min cruise)
  • Examples: towns, lakes, river bends, railway junctions, highways crossing track

DR vs Other Nav Methods

  • Dead Reckoning — calculations only; no external reference
  • Pilotage — visual landmark matching (NAV-009)
  • VOR — radio nav from ground station (NAV-010)
  • GPS — satellite position fix (NAV-011)
  • DR underpins all methods — always have a PLOG

Exam Memory Hooks

FORMULATime = Distance ÷ GS × 60 — use Ground Speed, not TAS, because GS is your actual speed over the ground.
WCAWind from the right → turn right (add WCA). Wind from the left → turn left (subtract WCA). WCA is measured from True Track to True Heading.
PLOGAlways file your PLOG with a responsible person before departure. If you go overdue, SAR uses your planned route and timings.
