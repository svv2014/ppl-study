NAV-011 — GPS Basics

Transport Canada · TP 12880E Ch.9 · AIM COM 3.0 · PPL Written Exam

GPS Display Terms — Key Abbreviations
Abbr.Full NameWhat It Means
DTKDesired TrackThe planned course from waypoint to waypoint (straight-line intended path)
TMGTrack Made GoodYour actual ground track (where you are really going, accounting for wind drift)
XTECross-Track ErrorDistance left or right of desired track; in NM. Steer to reduce XTE to zero.
BRGBearingDirection from your present position to the active waypoint; magnetic degrees
GSGround SpeedActual speed over the ground (knots); accounts for wind. Use for time/fuel calc.
ETEEstimated Time EnrouteTime remaining to reach the active waypoint at current ground speed
ETAEstimated Time of ArrivalPredicted clock time at destination (ETE + current UTC time)
RAIMReceiver Autonomous Integrity MonitoringGPS self-check that verifies signal integrity; required to be active for navigation
GPS Moving Map — Key Elements
DTK (blue dashed) — the straight-line desired course
TMG (amber) — actual track made good (wind is pushing you right)
XTE (red) — 1.2 NM right of course; steer left to correct
Waypoints (green) — named fixes in the GPS database

GPS gives a direct course between waypoints. Wind causes TMG to differ from DTK. Use the BRG field to steer toward the waypoint; XTE shows how far off you are.

GPS Database Basics

  • AIRAC cycle — database updates every 28 days; must be current for IFR approach use
  • VFR use: expired database OK for en route reference, but verify waypoint positions on current charts
  • Waypoints: airports (ICAO codes), VORs, intersections, user-defined
  • Direct-To (D→) function: straight line to any waypoint in database

GPS Limitations — VFR Use

  • Classified as supplemental aid for VFR — not sole navigation reference
  • RAIM alert = degraded accuracy; revert to primary nav (chart + pilotage)
  • Satellite signal loss, interference, and solar events can degrade or deny service
  • Always maintain positional awareness visually; GPS is a cross-check, not a replacement for looking outside

Exam Memory Hooks

DTK vs TMGDTK = where you want to go; TMG = where you're actually going. If wind pushes you off, TMG ≠ DTK and XTE increases. Steer toward the waypoint bearing (BRG) to reduce XTE.
RAIMRAIM = Receiver Autonomous Integrity Monitoring. If the GPS warns of RAIM failure, it cannot guarantee accuracy. Revert to chart + pilotage + VOR. Do not continue GPS navigation blindly.
SUPPLEMENTALGPS is not a primary nav aid for VFR in Canada. You must still be able to navigate by charts alone. The exam will test this — knowing GPS doesn't replace knowing pilotage and dead reckoning.
