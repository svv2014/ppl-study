GPS Satellite Geometry and Fix
Core Concepts

How GPS Works

  • Satellites transmit precise time signals from known orbital positions
  • Receiver measures time delay = distance (ranging)
  • Minimum 3 satellites for 2D fix (lat/lon only)
  • 4+ satellites required for 3D fix (lat/lon + altitude)
  • Accuracy: civilian GPS ~15 m horizontal (WAAS can improve to ~3 m)
  • HDOP (Horizontal Dilution of Precision) indicates geometric accuracy — lower is better

GPS Limitations

  • Signal shadowing: Deep valleys, canyons, urban canyons can block satellites
  • Jamming/spoofing: Military or civilian interference can degrade accuracy
  • True north by default: GPS measures true track — magnetic variation is applied by the unit's database (may be outdated)
  • Database currency: waypoints and airways must be current for IFR; VFR use still needs current VNC
  • No terrain warning unless TAWS/EGPWS installed separately
  • Selective Availability (SA) discontinued 2000 — no longer an issue

Important — VFR GPS Use

GPS is supplemental navigation for VFR — always carry current paper charts (VNC/VTA) and know how to navigate without GPS. GPS heading is TRUE unless the unit applies magnetic variation from its database. Verify the unit's variation matches your VNC chart. Never use GPS as sole-means for VFR flight planning.

Memory Hook
Memory Hook
  • GPS = True north by default. When ATC gives you a heading, it is magnetic. GPS track is true. Know the difference — add or subtract variation (~15°W in southern Canada).
  • 4 satellites = 3D fix: Need 3 for position, 4th for altitude. If only 3 in view, altitude is unreliable.
  • Never sole-means for VFR: GPS can fail, jam, or go out of date. Charts and pilotage are your backup.
  • XTK vs DTK: DTK is where you should go; XTK is how far off you are. Use XTK like a CDI needle.
