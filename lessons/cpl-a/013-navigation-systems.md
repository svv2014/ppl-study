# Lesson CAN-002: Navigation Systems — VOR, NDB, GPS, and RNAV

**Subject:** Advanced Navigation  
**Status:** Draft — content pending

**PPL-A Foundation:** PPL-A lessons NAV-010 (vor-navigation) and NAV-011 (gps-basics) cover the fundamentals. This CPL-A lesson extends to: NDB/ADF systems (not covered in PPL-A), area navigation (RNAV) concepts, RNP (Required Navigation Performance), database currency requirements for GPS/RNAV, and how these systems are used in commercial IFR-adjacent operations. Also covers system failure recognition and cross-checking multiple navigation sources.

Content to author: body narration, 5 quiz questions, source citations.
